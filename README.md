# cadastro-interesse-atendimento
Cadastro temporário para registrar o interesse em atendimento enquanto cadastro de MSRS estiver fechado

## Pré-requisitos

- node >=20.12.2
- pnpm >=9.2.0

## Install

```sh
pnpm install
```

## Usage

```sh
pnpm run dev
```

## Testes

```sh
pnpm run test
```
